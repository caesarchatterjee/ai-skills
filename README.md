# AI Skills Repository

A collection of reusable AI skills and capabilities.

## Repository Structure

```
ai-skills/
├── skills/
│   ├── skill-1/
│   │   ├── instructions.md
│   │   └── [skill-specific files]
│   ├── skill-2/
│   │   ├── instructions.md
│   │   └── [skill-specific files]
│   └── example-skill/
│       └── instructions.md (template)
├── README.md
└── .gitignore
```

## Getting Started

1. **Browse existing skills** in the `skills/` directory
2. **Create a new skill** by following the template in `skills/example-skill/instructions.md`
3. **Document your skill** with a clear `instructions.md` file

## Adding a New Skill

1. Create a new folder under `skills/` with a descriptive name
2. Add an `instructions.md` file documenting:
   - What the skill does
   - How to use it
   - Parameters and examples
   - Error handling
3. Include any supporting files needed
4. Update this README with your new skill

## Skill Template

See `skills/example-skill/instructions.md` for a complete template showing best practices for documenting your skills.

## Contributing

Feel free to add new skills and improve existing ones. Keep documentation clear and comprehensive.
